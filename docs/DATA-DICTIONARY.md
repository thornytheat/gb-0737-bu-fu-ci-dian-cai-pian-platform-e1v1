# 裁床数据定义

| 文件 | 必填字段 | 原始单位或定义 |
|---|---|---|
| `*-rolls.csv` | 卷号、布种、卷长、卷长单位、幅宽、幅宽单位 | 卷号为文本键。卷长最多 1000000 mm，幅宽最多 4000 mm |
| `*-defects.csv` | 疵号、卷号、坐标基准、类型、起点、终点、单位、安全余量、余量单位 | 基准为卷首或卷尾，类型为点或段，备注可空。仅表头表示该批已确认无疵记录 |
| `*-orders.csv` | 订单号、布种、最小幅宽、幅宽单位、净长、净长单位、单端缝份、缝份单位、数量、优先级 | 优先级为急或常，数量正整数。裁长等于净长加两端缝份 |

用 Decimal 把 `mm`、`cm`、`m` 或对应中文单位精确转换为整数毫米。小数允许最多 4 位，到毫米后不允许残余小数。全角数字按 NFKC 归一，允许规范千分组。必填字段中的空串、`-`、`null`、`n/a`、`待测`、`未知` 归为缺值。源文件 512 KiB、3000 条逻辑记录封顶。键保留文本样式。

## 从验布到禁切

CSV 以 UTF-8、带 BOM 的 UTF-8 和 GB18030 严格解码。重复表头和空行单独登记。每类文本键分开处理，字段归一后完全相同的记录保留首行。不同内容或同键含坏行时，全部相关记录隔离。语法不完整的文件直接失败。

所有区间是半开 `[起点, 终点)`。卷尾报数 `[a,b]` 换算为 `[卷长−b, 卷长−a]`。先拒绝反向和超卷，再换算与加余量。点疵正常占从定位点向前的一毫米，在卷尾端点则占最后一毫米。零长段疵归为错误。每个疵段向两端扩安全余量，限制到卷内，重叠或相接的区间合并。已知卷含隔离疵点即整卷封存。疵点关联到未登记卷时，该行进入隔离，须现场补卷号。

## 裁片组合与领卷

布种需一致，幅宽至少达到工单下限。每片及其紧随的刀口必须完整位于一个可用段内。最后一片也计刀口，刀口可恰好到达可用段右端。每卷先对连续可用段枚举可行片数组合，再在多卷之间合并数量状态，任何工单不得超量。方案依次比较急单完成片数、普通完成片数、合格片总长度、领用卷数和已开卷余料。前 3 项取最大，后 2 项取最小。同条件按卷号与稳定的段方案决策。换卷次数为开卷数减一，下限为零。

规划上限为 8 卷、4 个工单、12 个需求裁片和 24 个可用段。`PLAN_LIMIT` 提示拆分工单。参数只支持整数刀口 1–20 mm。切割模型按一维布卷规划，幅宽作为兼容条件，每次裁切按全幅占用长度。

## 勾稽与归档

卷长等于合格裁片、禁切区、刀口和未用段之和。封存卷整段归禁切。裁片与刀口也须互不重叠。三个来源分别核对原始、有效、重复和隔离条数。归档保存选用文件的 SHA-256、刀口宽度、规则版本、资源上限、分项总长与方案摘要。

相同输入和刀口归档时复用原批次。重跑重新读取文件并计算，摘要一致时添加核验事件。源摘要变化返回 `STALE_RUN`，保留旧批次。独立下载含运行清单和每阶段证据，不要求原文件存在。签条由当前已归档的选中卷生成。

## 两班分班作业单

分班在已归档批次的排程裁片上进行，只重排班次、不新增裁片。每卷各自枚举切分点：急单裁片整段归入一班，切分只允许落在同可用段内相邻两片共用的刀口上，禁切区两侧的段边界不是刀口，禁止在那里分班。目标依次为两班都有活、跨班卷数最少（少截断卷即少换卷）、两班换卷次数之和最少、班间片数最均衡，最后按卷号字典序稳定裁决。

每片与每段刀口恰好属于一个班次。跨班卷在作业单的余料交接中写明卷号、交接刀口坐标、所在可用段、一班收刀片、二班起刀片和卷内余料长度。`POST /api/runs/{id}/shift-sheets` 在单事务内停用旧版、写入新版并登记发布事件，任一步失败整体回滚，旧版作业单继续生效。作业单编号由批次与分班内容的哈希决定，同一作业重复或并发发布复用同一编号（返回 200），不会新增另一套裁片。重跑 `POST /api/shift-sheets/{id}/rerun` 重算分班，与发布摘要不一致时返回 `SHEET_STALE` 且不覆盖；历史版本按批次保留。
